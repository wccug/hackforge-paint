Build Instructions
==================

Building on Windows
-------------------

1. Go to an SDL release from e.g.,
   https://github.com/libsdl-org/SDL/releases

2. Choose the development package, e.g., SDL3-devel-3.4.4-VC.zip

3. Unzip the file.

4. Copy the contents to SDK3-SDK/, so that folder directly contains the subfolders "include" and "lib".

That's it. If you use the development package, the 'lib' folder also
contains the runtime DLL.

Building with MSBuild on Windows
--------------------------------

IMPORTANT: Exact directories might vary depending on your version of Windows and CPU architecture.

Following these steps will install the "Build Tools for Visual Studio" version 18 (2026) and 16 (2019) which will allow for the project to be built without needing to have or run Visual Studio.

1. Navigate to https://visualstudio.microsoft.com/downloads/ and scroll down to the second section named "Tools for Visual Studio".

2. Expand that section and click the download button for "Build Tools for Visual Studio 2026".

3. Once downloaded, run the executable. It will perform some initial setup before launching the installer.

4. Under "Workloads", check "Desktop development with C++" and any other options that you want then click install.

5. If you already have version 16 (2019) tools installed, GOTO step 8.

6. The project is configured to work with version 16 (2019) so those tools will also need to be installed along side the tools for version 18 (2026).

7. Download version 16 tools using: https://aka.ms/vs/16/release/vs_BuildTools.exe and then GOTO step 3.

8. Once complete, add "C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\MSBuild\Current\Bin" to your user's Path Environment Variable.

Tip: If you want an easier way to modify your Environment Variables, download and install Microsoft PowerToys: https://github.com/microsoft/PowerToys

9. Restart any open Powershell terminals.

10. Make sure you have SDL3 downloaded and configured as defined in the "Building on Windows" section above.

11. In the project's root directory (eg. "\Users\cppdev\git\hackforge-paint\"), run the following command: MSBuild.exe

12. If everything goes smoothly, a directory called "x64" should have been created, which contains the executable. It can be ran in the terminal with .\x64\Debug\hackforge-paint.exe

# Hackforge Paint - Linux Dependency Guide

This document outlines how to resolve and install the system libraries providing `<dbus/dbus.h>`. This header is required by the native Linux color picker implementation, which interfaces with the XDG Desktop Portal via D-Bus to invoke the native system color sampler.

# Installing D-Bus Development Libraries

The D-Bus development headers are not typically installed by default on desktop Linux distributions. You must install them using your distribution's package manager.

### 🔹 Ubuntu / Debian / Linux Mint / Pop!_OS
On Debian-based systems, the headers are provided by the `libdbus-1-dev` package:
```bash
sudo apt update
sudo apt install build-essential libdbus-1-dev pkg-config

Verifying the Installation

Before compiling, you can verify that your compiler and pkg-config can locate the D-Bus library paths and compiler flags.

Run the following command in your terminal:

pkg-config --cflags --libs dbus-1

Output Structure:

-I/usr/include/dbus-1.0 -I/usr/lib64/dbus-1.0/include -ldbus-1

(Note: The exact paths may vary slightly depending on whether your architecture is lib, lib64, or x86_64-linux-gnu).
3. Compilation

Once both SDL3 and D-Bus development packages are installed on your system, navigate to the source directory containing main.cpp, win32_colorpicker.cpp, and win32_colorpicker.h.

Compile the executable using the following universal string:

g++ main.cpp win32_colorpicker.cpp -o hackforge_paint `pkg-config --cflags --libs sdl3 dbus-1`

Run the Application:

./hackforge_paint

4. Troubleshooting
❌ Error: fatal error: dbus/dbus.h: No such file or directory

    Cause: The compiler cannot find the D-Bus headers.

    Fix: Ensure you installed the -dev or -devel version of the package matching your distribution (listed in Section 1), not just the runtime tool package.

❌ Error: Package dbus-1 was not found in the pkg-config search path.

    Cause: pkg-config cannot locate the library's .pc metadata file.

    Fix: Explicitly ensure pkg-config (or pkgconfig on Fedora) is installed. If you installed headers to a custom directory, append that path to your environment variables:
    Bash

    export PKG_CONFIG_PATH=/usr/local/lib/pkgconfig:$PKG_CONFIG_PATH

1. Install SDL3 from your package manager. Make sure to get the
   headers for building software.  On Debian-based distros this means
   installing the package `libsdl3-dev` instead of just `libsdl3`.

2. Create a build directory under the root directory of the
   checked-out repository, and run cmake therein:

   > mkdir build && cd build && cmake ..

   Notice the two dots above. This is a path parameter, which must be
   the top-level directory where the CMakeLists.txt file resides.

3. Build the executable. With the above cmake invocation, it should
   suffice to just type `make` in your build directory. Alternatively,
   run `cmake --build . --target hackforge-paint`
